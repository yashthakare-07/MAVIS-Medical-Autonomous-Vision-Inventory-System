# Future Scope

## MQTT Communication

The project proposes replacing HTTP communication with MQTT.

Expected benefits include:

- Lightweight communication
- Publish-subscribe architecture
- QoS-based reliability
- Reduced missed arrival events

## ESP32-CAM

The project proposes integrating an ESP32-CAM for onboard QR processing.

This would reduce dependence on external video streaming.

## Automated Payload Handling

The project proposes adding a mechanized payload-handling system.

Examples identified in the report include:

- 3-axis robotic arm
- Motorized payload mechanism

The purpose would be to reduce manual intervention during medicine pickup and delivery.
