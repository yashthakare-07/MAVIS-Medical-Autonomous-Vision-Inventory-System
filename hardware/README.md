# Hardware

M.A.V.I.S. uses a compact differential-drive robotic platform.

## Main Hardware

- ESP32
- IR sensor array
- L298N motor driver
- Two geared DC motors
- Lithium-ion battery pack
- DC-DC buck converter
- Smartphone IP Webcam
- Glass chassis
- Caster wheel
- Connecting wires

See [components.md](components.md) for component-level information.
